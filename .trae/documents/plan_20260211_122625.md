### 1. 变量命名深度优化 (Renaming)
我们将变量名修改为更具描述性的名称，使其意图一目了然：

**组件引用 (Components):**
*   `RB` -> **`RigidBody`**
*   `Anim` -> **`Animator`**
*   `SR` -> **`SpriteRenderer`**
*   `TR` -> **`TrailRenderer`**
*   `Effects` -> **`PlayerVFX`** (明确是视觉特效组件)
*   `feetPos` -> **`GroundCheckPos`** (明确用途)
*   `frontCheck` -> **`WallCheckPos`** (明确用途)
*   `attackPoint` -> **`AttackOrigin`** (攻击判定原点)
*   `weaponPivot` -> **`WeaponPivotTransform`**

**配置参数 (Settings):**
*   `amountOfJumps` -> **`MaxJumpCount`** (最大跳跃次数)
*   `jumpGravityScale` -> **`RisingGravityScale`** (上升重力)
*   `fallGravityScale` -> **`FallingGravityScale`** (下落重力)
*   `jumpBufferTime` -> **`JumpBufferDuration`** (缓冲持续时间)
*   `coyoteTime` -> **`CoyoteDuration`** (土狼时间持续时间)
*   `checkRadius` -> **`CheckRadius`**
*   `whatIsWall` -> **`WallLayer`**
*   `ground` -> **`GroundLayer`**
*   `platformFallForce` -> **`PlatformFallSpeed`** (因为它实际上设置的是速度而非力)

**运行时变量 (Runtime):**
*   `MoveInput` -> **`InputX`**
*   `workspace` -> **`WorkVector`**

### 2. 代码分区优化 (Regions)
重新组织代码结构，使其逻辑分层更清晰：
*   **删除** 旧的 `#region State Machine`。
*   **新建 `#region Components`**: 集中存放所有组件引用（Rigidbody, Animator, Check Transforms 等）。
*   **整理 `#region Settings`**: 包含所有 `[Header]` 配置项，按功能模块分组（Movement, Combat, Physics 等）。
*   **新建 `#region Runtime`**: 存放运行时变量（Input, Timers, Flags）。
*   **新建 `#region Inner FSM`**: 存放内部状态机类定义。
