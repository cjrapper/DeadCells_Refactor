## 四、维护约定（以后新增笔记，照这个来）

### ① 每份笔记开头必须有一行日期

```markdown
# 标题

> 最后更新：YYYY-MM-DD

> 用途：一句话说明这份笔记解决什么问题。
```

**改了内容就更新日期。**

### ② 文件名按"区"加前缀

| 区 | 前缀 | 例子 |
|---|---|---|
| 面试八股 | `知识库_` | `知识库_C#与Unity八股精讲.md` |
| 写代码速查 | `知识库_` | `知识库_Unity运行时UI速查.md` |
| 算法 | `知识库_算法_` | `知识库_算法_回溯与网格图.md` |
| 笔试 | `笔试_` | `笔试_C++速查.md` |
| 面试弹药 | `面试弹药_` | `面试弹药_项目Bug复盘.md` |
| 项目复盘 | `知识库_<系统>_` | `知识库_商店系统_完成总结.md` |
| 开发任务 | 放 `开发任务/` | `开发任务/Week1_金币掉落系统.md` |

### ③ 公开 vs 本地

`.gitignore` 里的规则决定哪些会上 GitHub：

| 会公开 | 只在本地 |
|---|---|
| `docs/开发任务/*` | `docs/知识库_*.md` |
| `docs/代码评审报告.md` | `docs/笔试_*.md` |
| `README.md` | `docs/面试弹药_*.md` |
| `Unity_API_Notes.md` | `docs/待问.md` |

**判断标准**：**面试弹药、求职材料、个人清单 → 不公开**；**开发过程记录 → 可以公开**。

### ④ 大文件不进 git

视频、录屏、超过 10MB 的素材一律 `.gitignore`。
