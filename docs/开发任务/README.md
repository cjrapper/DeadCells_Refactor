# 开发任务 · 总览（DeadCells Roguelike 化）

> 协作模式：**你手敲代码，我写任务书 + review**。每份任务书按「目标 → 架构 → 分步代码 → 验收 → 坑」组织，
> 每段代码带"为什么"注释 + 🎯面试考点标注。卡住随时贴报错。

## 路线（2.5 周版，穿插投递面试）

| 阶段 | 内容 | 产出 | 面试讲什么 |
|------|------|------|-----------|
| Day 1-2 | 素材替换 + Unity 检查 + **Build 出包** | 能双击运行的包 | 简历可甩链接 |
| Week 1 | 金币掉落 + 掉落表 | 击杀掉金币、拾取计数、UI 显示 | 数据驱动、对象池、权重随机 |
| Week 2 | 商店房间 + 道具系统 | 商店买卖、道具使用 | UI 栈、SO 道具数据 |
| Week 3 | 随机关卡（房间模板 + 门禁 + 种子） | 每局不同关卡 | 程序化生成、种子可复现 |
| Week 3 尾 | Boss 二阶段 + 死亡成长 + 出包 | 完整循环 Demo + 演示视频 | 多阶段 AI、完整游戏循环 |

## 风格
丝之歌卡通风：先 Kenney Toon 系列顶住（免费可商用），再并行磨 AI 生成的角色帧 / 手绘素材。
URP 2D 后处理（调色/描边/柔光）统一质感。

## 铁律（沿用 CLAUDE.md）
1. UI 引用 Awake 里 transform.Find，按钮 AddListener
2. 数据进 ScriptableObject，不硬编码
3. 事件中心解耦模块
4. Update 不 new、GetComponent 空判断
5. 不动 ThirdParty、不删注释、不重构无关代码
