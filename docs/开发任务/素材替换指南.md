# 素材替换指南（Sprite Sheet 切片 + 应用）

> Kenney Toon Characters 1 素材（CC0 免费商用）。先看"一、判断你的素材"再动手。

## 一、先搞清楚概念和你的素材

**Sprite Sheet（精灵表）**：很多小图拼在一张大图里（省内存、方便管理）。你问"这是图集嘛"——**不是**：
- **Sprite Sheet**：内容通常是一组**序列帧**（角色动画）或**零散素材**，靠"切片"拆开用
- **图集 Atlas**：把多张**独立图片**合并成一张纹理，目的是**合批降 DrawCall**（UI 用的）
- 但**操作流程一样**：都是"导入 → 告诉 Unity 一张图里有多个图 → 切成小图"

**Kenney Toon Characters 1 的特殊性**：这个包每个角色是**部件化**的（head/body/arm/leg 分开，可自由拼装换装），`character_xxx_sheetHD.png` 是部件总览大图。所以先打开图看看内容：
- **如果是"多行多列、每格同样大小的动作帧"** → 走"Grid 网格切片"
- **如果是"大小不一的零散部件各占一格"** → 走"Auto 自动切片"（按透明边缘切）
- 如果只是想要"拿来就能用的完整角色动画" → 这个包不合适，去 Kenney 下 **Toon Characters 2**（自带全套动画）或 **Monsters**（怪物动画）

## 二、导入设置（每个 png 都要做）

1. 把素材拖进 `Assets/Art/`（已经是了）
2. 选中贴图 → Inspector：
   - `Texture Type` = **Sprite (2D and UI)**
   - `Sprite Mode` = **Multiple**（一张图多个图！）
   - `Pixels Per Unit` = 按素材风格：像素风 16/32，卡通风 Kenney 一般是 **100**（如果替换后角色在场景里大小不对，就是它）
   - `Filter Mode` = **Point (no filter)**（像素风防模糊）；卡通风可 Bilinear
   - `Compression` = **None**（像素风防糊）
3. 点 **Apply**

## 三、切片（Sprite Editor）

1. 双击贴图 → 打开 **Sprite Editor**（或 Inspector → Sprite Editor 按钮）
2. 左上角 **Slice** 按钮：
   - **Grid by Cell Size**：如果帧是均匀网格 → 填每帧像素（比如 128x128），点 Slice
     - 技巧：填完看**网格线是否贴合每帧边缘**，不对就调数值重新 Slice
   - **Auto**：部件大小不一 → Type 选 Automatic，点 Slice（按透明边缘自动切）
3. 点右上角 **Apply** 保存
4. 左侧会列出切出的所有 Sprite，**选中每个可以重命名**（如 Idle_0、Run_0）——名字好认后面找起来快

## 四、应用

**测试单帧**：把切片产物（展开贴图的小三角）直接拖到场景物体/预制体的 SpriteRenderer 的 Sprite 上，看大小和显示对不对。

**替换角色动画**（玩家/敌人是 Animator + Animation Clip 的）：
1. Window → **Animation**（快捷键 Ctrl+6），选中玩家物体 → 左上角下拉选 clip（Idle）
2. 时间轴上会看到关键帧（菱形），每个关键帧引用了旧 Sprite
3. **全选关键帧**（框选）→ 在 Inspector 的 Sprite 槽里拖入新素材对应的帧（会整体替换）——如果新旧**帧数一致**，直接批量替换；不一致就删掉多余帧/补齐
4. 逐帧检查：动作方向对不对、有没有位移（素材原点不一致会导致角色跳动）
5. 对 Idle/Move/Jump/Fall/Dash/Attack 每个 clip 重复

## 五、背景替换

- **单张整图背景**（视差层）：直接拖到背景 SpriteRenderer 上，调 PPU 和 Sorting Layer
- **Tileset（地砖）**：切片后要用 Tile Palette（Window → 2D → Tile Palette）重新铺——工作量较大，可后置
- 你的背景如果是 DynamicBackground.controller 那套动画背景：换 Sprite 后 Animation 里的帧同样要换（和角色一样操作）

## 六、常见坑

| 症状 | 原因 | 解决 |
|------|------|------|
| 角色在场景里巨大/巨小 | PPU 和原素材不一致 | 调 Pixels Per Unit（原角色用的多少就对多少） |
| 切片后帧边缘有别人 | Grid 尺寸不对/有留白 | 换 Auto 切 / 微调 Cell Size |
| 图片模糊 | Filter 不是 Point / 压缩没关 | 见"导入设置" |
| 动画替换后角色乱跳 | 新素材每帧原点不一致 | 动画里逐帧调 Position，或用 Sprite Editor 调 pivot |
| 换完是紫色/透明 | 材质问题（少见） | 确认 SpriteRenderer 的 Sprite 已赋值 |

> 提醒：替换前把旧素材目录备份或记下旧 PPU 值（角色大小对不上的时候要改回来对比）。
