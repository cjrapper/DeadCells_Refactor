## 一、为什么把这两个放一起

**网格图 DFS 和二叉树 DFS 是同一个东西，只是"递归方向"和"递归边界"不同。**

| | **二叉树** | **网格图** |
|---|---|---|
| 递归入口 | 根节点 | 网格图的某个格子 |
| 递归方向 | 左儿子和右儿子 | 一般为左右上下的相邻格子 |
| 递归边界 | 空节点（或叶节点） | **出界、遇到障碍、已访问** |

**理解了二叉树递归，网格图就是换个方向。**

回溯也是同一套递归，区别是**要"恢复现场"**（撤销选择）。

> **一句话区分 DFS 和 BFS**：
> DFS 是不撞南墙不回头；BFS 是往水塘扔石头，荡起一圈圈涟漪（先访问近的，再访问远的）。

## 二、模板（C++，笔试用）

### 2.1 网格图 DFS（算连通块大小）

适用于：**连通块个数、连通块大小**。

```cpp
int m, n;
vector<vector<bool>> vis;

// 返回当前连通块的大小
int DfsGrid(vector<vector<char>>& grid, int i, int j) {
    vis[i][j] = true;
    int size = 1;
    int dx[4] = { 0, 0, -1, 1 };
    int dy[4] = { -1, 1, 0, 0 };

    for (int d = 0; d < 4; d++) {
        int x = i + dx[d], y = j + dy[d];
        // 边界判断 + 题目条件判断 + 未访问
        if (x < 0 || x >= m || y < 0 || y >= n) continue;
        if (grid[x][y] != '1' || vis[x][y]) continue;   // ← '1' 按题意改
        size += DfsGrid(grid, x, y);
    }
    return size;
}

// 主函数里
int CountIslands(vector<vector<char>>& grid) {
    m = grid.size(); n = grid[0].size();
    vis.assign(m, vector<bool>(n, false));
    int count = 0;
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            if (grid[i][j] == '1' && !vis[i][j]) {   // ← 按题意改
                DfsGrid(grid, i, j);
                count++;
            }
    return count;
}
```

### 2.2 网格图 BFS（算最短距离）

适用于：**最短路、最少步数、逐层扩散**。

```cpp
// 返回从 (sx, sy) 出发到各格子的最短距离，到不了的是 -1
vector<vector<int>> BfsGrid(vector<vector<char>>& grid, int sx, int sy) {
    int m = grid.size(), n = grid[0].size();
    vector<vector<int>> dis(m, vector<int>(n, -1));

    dis[sx][sy] = 0;
    queue<pair<int,int>> q;
    q.push({sx, sy});

    int dx[4] = { 0, 0, -1, 1 };
    int dy[4] = { -1, 1, 0, 0 };

    while (!q.empty()) {
        int i = q.front().first;
        int j = q.front().second;
        q.pop();
        for (int d = 0; d < 4; d++) {
            int x = i + dx[d], y = j + dy[d];
            if (x < 0 || x >= m || y < 0 || y >= n) continue;
            if (grid[x][y] != '.' || dis[x][y] != -1) continue;  // ← 按题意改
            dis[x][y] = dis[i][j] + 1;
            q.push({x, y});
        }
    }
    return dis;
}
```

> **多源 BFS**（如「腐烂的橘子」「01 矩阵」）：把所有源点**一开始全部入队**、dis 全设 0，其余代码不变。

### 2.3 回溯模板（子集型 / 排列型）

**回溯 = DFS + 恢复现场。** 核心就一句：**做完选择，递归；递归回来，撤销选择。**

```cpp
// ---------- 类型一：子集型（每个元素「选或不选」）----------
void DfsSubset(int i, vector<int>& nums, vector<int>& path, vector<vector<int>>& ans) {
    if (i == (int)nums.size()) { ans.push_back(path); return; }

    DfsSubset(i + 1, nums, path, ans);      // 不选 nums[i]

    path.push_back(nums[i]);                 // 选 nums[i]
    DfsSubset(i + 1, nums, path, ans);
    path.pop_back();                         // ★ 恢复现场
}

// ---------- 类型二：排列型（枚举「选哪个」）----------
void DfsPermute(vector<int>& nums, vector<bool>& used,
                vector<int>& path, vector<vector<int>>& ans) {
    if (path.size() == nums.size()) { ans.push_back(path); return; }

    for (int i = 0; i < (int)nums.size(); i++) {
        if (used[i]) continue;
        used[i] = true;
        path.push_back(nums[i]);
        DfsPermute(nums, used, path, ans);
        path.pop_back();                     // ★ 恢复现场
        used[i] = false;
    }
}
```

**两种类型的区别**（这是回溯最容易混的地方）：
| | 子集型 | 排列型 |
|---|---|---|
| 问法 | 选哪些（顺序无关） | 怎么排（顺序有关） |
| 每层选择 | 第 i 个元素选或不选 | 从没用过的里挑一个 |
| 需要的辅助数组 | 无 | `used[]` |
| 代表题 | 78. 子集、39. 组合总和 | 46. 全排列、22. 括号生成 |

## 四、做题时的四个提醒

1. **十分钟没思路就看题解，别硬耗。** 灵茶的题解质量很高，看完**关掉重写一遍**才算做过。
2. **"恢复现场"是回溯唯一的坑。** 每次递归返回后，把 `path` 和 `used` 恢复成进递归前的样子。
3. **网格图先把边界判断写对**：`x < 0 || x >= m || y < 0 || y >= n`。这行写错会 RE 或死循环。
4. **DFS 记得标记已访问**，否则会无限递归爆栈。
