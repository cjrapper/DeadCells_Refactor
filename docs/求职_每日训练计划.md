# 求职每日训练计划

> 最后更新：2026-11-17
>
> **P0：求职。** 毕设和实习会自动找上门，不主动排进这张表。
> **核心判断**：缺口不是"知识量"，是**"给需求能拆出结构"的能力** —— 所以练法要能验证，不能只"想"。

---

## 0. 三条规则

1. **每天 1 小时，结构固定** —— 不用每天做决定，只要执行
2. **断一天没事，断三天危险** —— 打卡的唯一作用是看见断线
3. **每一块都要"输出"** —— 打字复述 / 敲代码 / 填表。**只看不算完成**

**为什么只有 1 小时**：太长必崩，太短无效。1 小时是能持续的上限。

## 2. 每日三块怎么做

## 2.1 主动回忆（20 分钟，**打字复述**）

> **为什么用打字不用口述**：宿舍出声不方便；而且打字能回看、能对比、能积累。

**流程：**

```
① 看一节笔记                     5 min
② 合上笔记，打开记事本，把这一节讲一遍（打字）   10 min
③ 对照笔记，把漏掉的写在纸上      3 min
④ 加一个"改造题"（见 4.1）        2 min
```

**关键**：② **必须合上笔记**。开着笔记打字 = 抄，不算回忆。

**怎么判断这节"过了"**：
- 能不看笔记打出 **80% 的要点** → 过
- 打完发现漏了一半 → **明天再做一次这一节**

**记录**：打卡表里写"今天回忆的是哪一节"，方便隔几天回头复习。

## 2.2 算法（30 分钟，**按时间填不按道数**）

```
21:35 - 21:40   挑一道【不熟题型】的题
21:40 - 22:05   做（做不出来就看解析）
22:05 前        看完解析 → 【关掉解析，自己重敲一遍】
```

**规则：**

| 规则 | 说明 |
|---|---|
| **必须有一道"不熟"的** | 简单题 5 分钟做完不算数，考的不是熟练度 |
| **做不出来先看解析** | 硬耗 30 分钟没有收益，**看懂 + 重敲**才是收益 |
| **重敲必须关掉解析** | 照着抄一遍等于没做 |
| **时间到了就停** | 不追求"做完"，追求"今天碰了不会的" |

**题型顺序**（按你之前的缺口）：

```
第 1 周：DFS / BFS（网格、图）
第 2 周：回溯（排列、子集、组合）
第 3 周：滑动窗口 + 堆
第 4 周：简单 DP
```

参考：[知识库_算法_回溯与网格图.md](知识库_算法_回溯与网格图.md)

## 3. 每周额外（周末 30~40 分钟）

工作日只做上面三块。**周末加一次"设计练习"**，二选一：

### 3.1 练法 A：反推已有系统（推荐，能自我验证）

```
① 挑一个你项目里的系统（商店 / 背包 / 武器 / 事件中心 / 敌人状态机）
② 回答三个问题：
   Q1 这个系统由几个类组成？各自负责什么？
   Q2 如果要加【某个功能】，要改哪几个文件？
   Q3 如果要加【某种新类型】，要改哪几个？
③ 【去代码里验证】—— 搜一下，看你猜的"改 2 个文件"实际是不是 2 个
④ 猜错的地方就是你要理解的设计边界
```

**为什么这个最有效**：**答案能在代码里验证。** 不是空想。

### 3.2 练法 B：20 分钟设计题

```
给自己一个假需求，【只写设计，不写代码】：

  1. 需要哪些类（3~6 个）
  2. 每个类一句话职责
  3. 数据放哪（SO / 运行时 / 存档）
  4. 一次核心操作的时间顺序（5~8 行流水账）

时间到就停，写完对照 3.1 的方法验证。
```

## 5. 打字专项（**上班时顺手练，不占晚间时间**）

### 5.1 问题定位

| 区域 | 状态 |
|---|---|
| 左手 QWER / ASDF / ZXCV | ✅ 熟，不需要看 |
| 右手 J K L ; | ✅ 熟（游戏练的） |
| **右手上排 U I O P** | ❌ **重灾区** |
| **右手下排 M , . /** | ❌ **重灾区** |
| 拼音键序（如 qiáng 打成 qaing） | ❌ 顺序错 |

### 5.2 核心动作：**先回基准位，再伸手**

```
右手四指放 J K L ;
   → 往上打 U I O P
   → 回 J K L ;
   → 往下打 M , . /
   → 回 J K L ;
```

**F 和 J 上有凸起 —— 那是盲打锚点。每次先摸到它们。**

### 5.3 每天 3 分钟的词组（上班时随手打）

| 练哪排 | 打这些 |
|---|---|
| 上排 | ming / min / niu / liu / guo / hui / piao |
| 下排 | men / mian / nian / bian / ming |
| 混排 | qiang / xiong / zhuang / shuang / chuang |

### 5.4 硬件检查

**磁轴键盘的触发行程**：如果设在 0.2~0.5mm（游戏档），手指没按实就会触发 → 误触增加。
**去驱动里调到 1.5~2.0mm（打字档）。**

> 这条可能比练一周都管用 —— 如果现在触发太浅，你一直在跟硬件打架。

## 附：为什么这套结构是这样设计的

| 设计 | 原因 |
|---|---|
| **每天 1 小时，固定三块** | 你崩在"每天该干嘛"的决策上，不是能力上。**结构固定就不用决定** |
| **打字放上班** | 打字不需要整块时间，用"顺手练"效率更高 |
| **回忆用打字不用口述** | 宿舍不方便出声；打字能回看、能对比 |
| **算法按时间不按道数** | 简单题 5 分钟一道，凑数没意义。**重点是有没有碰到不会的** |
| **回忆后加"改造题"** | 把"知识"和"设计能力"连起来，**不额外占时间** |
| **周末做反推练习** | 你的真缺口是"给需求拆结构"，而**反推是唯一能自我验证的练法** |
| **打卡只要一行** | 填表超过 30 秒就不会坚持 |

## 断线了怎么办

**断 1~2 天** → 正常，继续。

**断 3 天以上** → 不要"补回来"（补不回来的，只会更抵触）。
**直接把当天当作第 1 天重新开始**，忘掉之前断了多久。

> 习惯中断后最危险的不是"少学了几天"，是**"我失败了"这个念头**。
> 它比断线本身伤人得多。
